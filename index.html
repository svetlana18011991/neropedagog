Создаём цифровые материалы с нейросетями: интерактивный тренажёр, рабочую тетрадь, публикацию в интернете и собственную библиотеку готовых решений.

Рабочая тетрадь

От структуры темы до цельного материала: теория, разборы, тренажёр и ответы.

02

Создаём большую рабочую тетрадь

Здесь можно оставить основной промпт, который участники копируют и адаптируют под свой предмет и тему.

Я учитель [предмет]. Создай структуру большой рабочей тетради по теме «[тема]» для [класс] класса.

Для каждого смыслового блока предусмотрите:
— краткую теорию;
— понятный алгоритм;
— полностью разобранный пример;
— типичные ошибки;
— тренировочные задания от простого к сложному;
— самостоятельные задания;
— ответы и решения для учителя.

Сначала покажи только структуру тетради. Не создавай весь материал, пока структура не будет утверждена.

После утверждения структуры создавай материал по разделам. Перед финальной выдачей проверь задания, ответы и соответствие всем моим требованиям.

03

Из файла — в готовую ссылку

Шаг 1. Сохраните код тренажёра как index.html.

Шаг 2. Откройте Netlify Drop.

Шаг 3. Перетащите файл index.html или папку проекта в окно загрузки.

Шаг 4. Дождитесь публикации и скопируйте готовую ссылку.

Пример 01

Рабочий лист

Разместите рядом тот самый промпт, по которому был создан этот материал.

Создай рабочий лист по теме «[тема]» для [класс] класса.

Структура:
1. Краткое правило.
2. Один полностью разобранный пример.
3. Три задания с опорой.
4. Пять заданий для самостоятельной работы.
5. Одно задание повышенного уровня.
6. Ответы отдельно.

Оставь достаточно места для решения и не перегружай страницу текстом.

Пример 02

Интерактивный тренажёр

Карточка уже готова — останется заменить изображение и ваш финальный промпт.

Создай интерактивный тренажёр по теме «[тема]» в одном HTML-файле.

Требования:
— задания показываются по одному;
— есть поле для ответа;
— после ответа ученик получает обратную связь;
— при ошибке сначала даётся подсказка, а не готовое решение;
— ведётся счёт правильных ответов;
— в конце отображается результат;
— дизайн современный, спокойный и удобный на телефоне.

Выдай полный готовый HTML-код, который можно сохранить как index.html и открыть в браузере.
