02

Создаём тетрадь без теории

Этот промпт можно использовать как основу, если вы хотите быстро собрать тренировочную рабочую тетрадь с перечнем заданий, без длинных объяснений.

Я учитель математики. Создай рабочую тетрадь по ВПР для 7 класса, задание 1.

Требования:
— тетрадь должна быть без теоретического блока;
— не нужно давать длинные объяснения и разборы;
— основной формат: перечень заданий для тренировки;
— задания нужно расположить от более простых к более сложным;
— оформи материал аккуратно, современно и удобно для печати;
— оставь место для записи ответов или краткого решения;
— можно разделить задания на небольшие тематические блоки;
— в конце отдельно дай ответы для учителя.

Сначала предложи структуру тетради. После утверждения создай полный материал.

Отдельный шаг

Как разместить на Netlify

Короткая памятка: после создания HTML-файла вы быстро превращаете его в готовую ссылку для учеников и коллег.

03

Из файла — в ссылку

Шаг 1. Сохраните код тренажёра как index.html.

Шаг 2. Откройте сервис Netlify Drop.

Шаг 3. Перетащите файл index.html или папку проекта в окно загрузки.

Шаг 4. Дождитесь публикации, протестируйте сайт и скопируйте готовую ссылку.

Рабочий лист

Разместите рядом тот самый промпт, по которому был создан этот материал.

Создай рабочий лист по теме «[тема]» для [класс] класса.

Структура:
1. Краткое правило.
2. Один полностью разобранный пример.

Пример 02

Интерактивный тренажёр

Карточка уже готова — останется заменить изображение и ваш финальный промпт.

Создай интерактивный тренажёр по теме «[тема]» в одном HTML-файле.

Требования:
— задания показываются по одному;
— есть поле для ответа;
— после ответа ученик получает обратную связь;
— при ошибке сначала даётся подсказка, а не готовое решение;
— ведётся счёт правильных ответов;
— в конце отображается результат;
— дизайн современный, спокойный и удобный на телефоне.

Выдай полный готовый HTML-код, который можно сохранить как index.html и открыть в браузере.
